# Student Management System

## Project Description
A console-based Student Management System developed using C++. It allows users to manage student records through a simple menu-driven interface.

## Features
- Add new student records
- Display all student records
- Search students by roll number or name
- Update student information
- Delete student records
- Validate user inputs
- Store student records in a text file (`students.txt`)

## Technologies Used
- Programming Language: C++
- Compiler: GCC (g++)
- Standard: C++17
- Editor: Visual Studio Code

## Project Files
- `main.cpp` – Main source code
- `students.txt` – Student record storage
- `student.exe` – Compiled executable

## How to Compile
```bash
g++ -std=c++17 -Wall -Wextra main.cpp -o student.exe
```

## How to Run
```bash
./student.exe
```

On Windows PowerShell, run:
```powershell
.\student.exe
```
